Mandelbrot

The set of complex c for which z → z² + c, started at zero, never runs away. Drag to move, scroll to zoom, and point at a bulb to be told its period.

At the limit of the fixed-point arithmetic, around 2−220. Past here even the reference orbit cannot separate one pixel from the next.

point at the set zoom 1× at depth cores

The escape test is a theorem in itself: if ever |z| > 2 the orbit is certain to run away, which is the only reason a picture can be drawn in finite time. Douady and Hubbard proved the set connected; Shishikura proved its boundary has Hausdorff dimension 2.

Mandelbrot in WebAssembly

The same explorer, with the escape-time kernel compiled to WebAssembly instead of run as JavaScript. Open it beside the JavaScript one and compare the timings; the pictures are the same to within one level of one colour channel.

At the limit of double precision — past here neighbouring pixels round to the same number and the picture goes blocky.

point at the set zoom 1× at depth cores

The module is 692 bytes, assembled byte by byte by tools/build_wasm.py because this machine has no WebAssembly toolchain. It has no logarithm instruction, and the smooth colouring needs two per escaped pixel, so log2 is taken from the float's own bits: the exponent gives the integer part exactly and four terms of the arctanh series cover the mantissa.
